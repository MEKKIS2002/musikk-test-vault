# Music Vault – GitHub Pages version

Denne mappen er en oppdelt versjon av originalfilen.

## Struktur

```text
index.html
css/styles.css
js/script-01.js ... js/script-21.js
assets/favicon.png
```

## Bruk på GitHub Pages

Last opp hele innholdet i denne mappen til repoet ditt. `index.html` må ligge i roten av repoet eller i den mappen GitHub Pages publiserer fra.

## Merk

JavaScript-filene er nummerert for å bevare samme kjørerekkefølge som i originalfilen. Det er tryggere enn å prøve å gjette funksjonsnavn og dele dem manuelt.
